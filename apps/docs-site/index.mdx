# NiceEval

**Write evals like unit tests. Compare Agents through experiments.**

</div>

You changed a prompt, switched models, wrote a new Skill for a coding Agent, or tuned an NPC in an LLM game. Now you want to know whether it actually improved. With NiceEval, you define success in TypeScript, then run, score, and compare repeatedly. When something fails, you can inspect what the Agent actually did.

Everything runs on your own machine and in your CI. No account required.

## Common questions

<AccordionGroup>
  <Accordion title="Do I need an account?">
    No. Evals and result inspection run locally. You only need a Sandbox Provider such as Docker or E2B when the subject under test needs an isolated environment.
  </Accordion>
  <Accordion title="Can I connect an Agent written in another language?">
    Yes. Evals and Adapters use TypeScript, but your application can use any language. An Adapter calls your existing API over HTTP, gRPC, or WebSocket. See [Adapter](/explanation/adapter).
  </Accordion>
  <Accordion title="Can I use it in CI?">
    Yes. Run the same `niceeval exp` command in CI. Its exit code indicates whether the evals passed. See [CI integration](/tutorials/ci-integration).
  </Accordion>
</AccordionGroup>

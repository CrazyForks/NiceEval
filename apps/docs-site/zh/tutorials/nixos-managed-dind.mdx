在 NixOS 上运行需要 Docker 的评估任务时，使用 Incus VM。评估配置与其它 Linux 宿主相同，见[让 Agent 在 Sandbox 中运行 Docker](/zh/tutorials/docker-in-docker)。

## 交给管理员准备的内容

管理员需要部署 Incus、运行 project、storage pool、可信基础镜像和 `/etc/niceeval/incus-provider.json`，并授予日常用户所需的访问权限。正式环境需要专用存储和可核验的容量；开发环境需要独立配置。

NiceEval 仓库中的 `nixosModules.default` 和 `nixosModules.docker-profiles` 提供 Docker Profile 配置，不能部署本页需要的 Incus 环境。不要把 `services.niceeval.dockerProfiles` 的服务启动成功当成 Incus 已准备完成。

本页不提供 Incus 的一键部署 module。宿主变更应由系统配置负责，评估项目里的 npm 依赖不会安装或更新这些服务。

## 用日常用户检查环境

在已经安装 NiceEval 的评估项目中运行：

```bash
pnpm exec niceeval sandbox provider doctor incus
```

使用开发环境时运行：

```bash
pnpm exec niceeval sandbox provider doctor incus --development
```

`doctor` 只读核对配置、可信镜像、对象和容量。权限错误应由管理员修正，不要通过 `sudo pnpm exec niceeval ...` 绕过日常用户的权限检查。

## 连接 Experiment

从管理员取得完整镜像 digest、project 和 storage pool，并按 [Incus 配置步骤](/zh/tutorials/docker-in-docker#在-experiment-里选择-incus)填入 `incusSandbox()`。开发环境必须显式设置 `acceptDevelopmentDomain: true`。

先运行实验的 `--dry` 检查能力和环境选择，再进行实际评估。宿主服务通过检查与实际评估成功是两项独立验证。

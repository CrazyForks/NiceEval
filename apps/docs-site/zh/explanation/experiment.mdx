Experiment 说明对着哪个 Agent、用哪个模型、开哪些 flags、跑几次。它用来比较模型、prompt 和功能开关：`flags` 就是 A/B 测试里的 feature flag，一个 Experiment 是一组 flag 取值。

## 一个 Experiment 里有什么

Experiment 是 `experiments/` 下可签入的 TypeScript 文件，核心就几个字段：

```ts
// experiments/concise.ts
export default defineExperiment({
  description: "简洁 prompt 变体",
  agent: webAgent({ baseUrl: "https://staging.example.com" }),  // 已配置好的 agent 实例
  model: "gpt-5.4",                    // 经 ctx.model 透传给 Adapter
  flags: { promptVariant: "concise" },  // 经 ctx.flags 透传;eval 里是 t.flags
  attempts: 3,                         // 每条 eval 跑几次(对抗随机性)
});
```

- `agent`：评谁。这里放已经配置好的 Adapter 实例。被测系统的地址和鉴权在创建实例时传给 Adapter，不写进 Experiment 的其它字段。
- `model` / `flags`：交给 Adapter 的实验条件。`flags` 只接受扁平的字符串、有限数字或布尔值，NiceEval 不解释它们的含义。Adapter 声明了 `parseFlags` 时，先校验和规范化，再经 `ctx` 交给 Adapter；Adapter 随请求转发，应用按值切换行为。模型对比（Tier 1）和功能 A/B（Tier 3）都走这条路，见[接入等级](/zh/explanation/tier)。
- `attempts`、`budget`、并发、`sandbox` 等运行参数：怎么跑、跑多少。完整字段见[编写实验](/zh/tutorials/write-experiment#常用字段)。

Experiment 还有一对实验级 Hook `setup` / `teardown`：整个实验只跑一次，在你自己的机器上执行，用来起停所有 Attempt 共享的服务（比如一条到内网服务的隧道、一个实验专用的 mock server）。

`setup` 在这个实验的第一个 Attempt 开始前执行。`teardown` 在全部 Attempt 结束后执行，运行被中断时也会执行；但只有 `setup` 已经执行过，`teardown` 才会执行。

要在 Sandbox 里为整个实验准备环境，把准备步骤挂在 `sandbox` 字段的 `.before()` 上。内容不变的步骤下次可以直接沿用；动态回调可以用 `context.onCleanup()` 登记收尾。写法见[启动实验共享服务](/zh/tutorials/experiment-services)与[Sandbox · 按顺序准备 Sandbox](/zh/tutorials/sandbox-providers#按顺序准备-sandbox)。

同一个实验里，不同评估用例需要不同的预制环境时，把指定预制环境的 `sandbox` 配置写在各评估用例上，Experiment 就不再指定。重复的配置用普通的 TypeScript 函数复用，不需要额外注册。同一个 Experiment 仍然能覆盖全部评估用例，NiceEval 会逐条把评估用例的配置和 Experiment 的配置合在一起。写法见[编写实验 · 不同评估用例需要不同环境](/zh/tutorials/write-experiment#不同评估用例需要不同环境)。

## 矩阵对比

要比较的每个变体写一个 Experiment 文件：两个模型就是两个文件，只差 `model` 一行。prompt A/B 就是只差一个参数。同一批评估用例在多个 Experiment 下各跑一遍，再比较同一时刻已发布的结果。每个 Experiment 按自己跑的评估用例计算分母，不会硬凑一个共同的交集。适合比什么、结果怎么读，见[编写实验](/zh/tutorials/write-experiment#比较两个模型)。

只用于报告归类、不影响运行过程的值写进 `labels`。它们记在 Run 上，不会传给 Adapter 或评估用例。改了 `labels` 再运行，会建立一个带新标注的 Run，没受影响的旧结果照常沿用；历史 Run 保留当时的 `labels`。
